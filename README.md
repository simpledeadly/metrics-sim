# metrics-sim

Симулятор метрик RAG-сервиса.

## Стек
- Python 3.11
- PostgreSQL 15
- Docker

## Автор
- simpledeadly
- github.com/simpledeadly

## Запуск
docker compose up -d

## Статус
В разработке.

## Путь
init, add, commit, push, pull, fetch
параллельные ветки с двух машин
merge с конфликтом и его разрешение
rebase — перенос ветки поверх обновлённого main
интерактивный rebase — squash трёх мусорных коммитов в один
cherry-pick — взял один конкретный коммит из чужой ветки
stash — спрятал незаконченное, переключился, вернулся
reset --hard — намеренно потерял коммит
reflog — нашёл и восстановил потерянное
теги — пометил релиз
